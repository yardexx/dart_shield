# Reporters

`dart_shield` supports multiple output formats to suit different environments (local development vs. CI/CD).

You can select a reporter using the `--reporter` flag with the `analyze` command.

## Console Reporter (Default)

The console reporter is designed for human readability. It prints a summary of issues found, grouped by analyzer, with severity icons and file locations.

**Usage:**
```bash
dart_shield analyze --reporter console
```

**Sample Output:**
```text
🛡️  SHIELD ANALYSIS REPORT
==================================================
✅ [code] found 0 issues (120ms)
==================================================
Total Issues Found: 0
```

## JSON Reporter

The JSON reporter outputs a structured JSON file, ideal for parsing by CI/CD tools or other automated systems.

By default, it writes to `shield_report.json` in the current directory.

**Usage:**
```bash
dart_shield analyze --reporter json
```

**Sample Output (`shield_report.json`):**
```json
[
  {
    "type": "success",
    "analyzer": "code",
    "duration_ms": 145,
    "issues": [
      {
        "ruleId": "avoid_hardcoded_secrets",
        "message": "Hardcoded secret detected: MySecretKey",
        "severity": "high",
        "context": {
          "file": "lib/main.dart",
          "line": 10,
          "column": 20
        }
      }
    ]
  }
]
```

## Both

You can generate both console output and a JSON report simultaneously.

**Usage:**
```bash
dart_shield analyze --reporter both
```
