# Quickstart

## Installation

Install dart_shield using:

```sh
dart pub global activate dart_shield
```

If you want to install specific version:

```sh
dart pub global activate dart_shield <version>
```

{% hint style="warning" %}
If this is your first CLI package, you might need to [setup PATH variable](https://dart.dev/tools/pub/cmd/pub-global#running-a-script-from-your-path).
{% endhint %}

## Initialisation

In root of your Dart/Flutter project, initialise dart\_shield using:

```sh
dart_shield init
```
## Running Analysis
dart_shield is build upon [analysis_server_plugin](https://pub.dev/packages/analysis_server_plugin) so any code threat is automatically detected by Dart analysis server.

`dart init` automatically enabled this analysis plugin in analysis_options.yaml as well as provided default configuration.

If you want to run analysis by hand, you can run default dart analyzer:
```sh
dart analyze <analyzed-folder>
```

If you want to run analysis but only care about issues reported by dart_shield, you can run:
```sh
dart_shield analyse <analyzed-folder>
```
