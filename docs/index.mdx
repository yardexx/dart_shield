## What is dart_shield?

`dart_shield` is a Dart-native Static Application Security Testing (SAST) tool that scans your codebase to identify potential security risks and breaches.

It detects security flaws such as:
* Hardcoded endpoints and API keys.
* Vulnerable cryptography (weak hashing algorithms, insecure random generators).
* Insecure HTTP connections.

## Motivation

In modern development, security is often an afterthought, but even small vulnerabilities can lead to major risks.

`dart_shield` is designed to catch these issues before they become problems, ensuring your code is as strong as your features. Instead of pushing security aside, relying on manual checks, or risking oversight, `dart_shield` acts as another handy tool in your workflow (just like your linter or `dcm`), allowing you to focus on building.

Security shouldn't have to be a trade-off—you can build secure applications efficiently while focusing on delivering your idea.

## Core Values

`dart_shield` is built around a few key principles:

### Simple
We leverage existing, familiar practices from the community rather than inventing new solutions. By adopting the proven architectures used within the Dart community, `dart_shield` stays in line with what developers already know ([Principle of Familiarity](https://en.wikipedia.org/wiki/Mere-exposure_effect)). This makes the tool easy to adopt and integrate into any project.

### Open-source
Security should be accessible to everyone. Whether your project is large or small, security should not be limited by budget.

That’s why `dart_shield` is free and open-source. This ensures transparency—anyone can review the code, identify issues, and contribute improvements. This collaborative approach strengthens the tool and keeps it reliable for all users.
